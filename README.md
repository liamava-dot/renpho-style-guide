# RENPHO Style Guide (2026)

Internal style guide for the RENPHO packaging and content writing team. Covers terminology, formatting rules, compliance guidelines, and product-specific copy standards.

## Live Page

After enabling GitHub Pages, the guide is available at:  
`https://YOUR-USERNAME.github.io/REPO-NAME/`

## What's Inside

- **General** — Grammar, capitalization, units & measurements, spacing rules, instruction terminology, technical terms
- **Packaging** — Front/Back of Box structure, USP summary guidelines, symbol rules
- **Amazon** — FSA/HSA template, prohibited keywords, bullet point guidelines
- **Compliance** — Banned medical terms, FDA terminology, LED mask regional naming, product-specific restricted phrases with risk levels
- **Templates** — Reusable boilerplate (warranty, IMA endorsement, Climate Pledge, app disclaimers)
- **Products** — Category-specific terms for Eye Massager, Scale, Foot Massager, Massage Gun

## Features

- Tab-based navigation
- Full-text search with keyword highlighting
- Multi-keyword support (space-separated, AND logic)
- Press Enter to jump between matches
- Collapsible sections

## Setup

No build step required. Just a single `index.html` file.

1. Rename `renpho-style-guide.html` to `index.html`
2. Push to your repo
3. Enable GitHub Pages (Settings → Pages → main branch, root)

## Maintenance

Edit `index.html` directly to add or update rules. Each section uses `data-categories="tabname"` to control which tab it appears under.
